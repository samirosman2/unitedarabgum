# United Arab Gum LLC — Corporate Website

Production-ready, bilingual (English / Arabic with full RTL/LTR), static MVP website built with **Next.js 15 App Router**, **TypeScript**, and **Tailwind CSS**.

## Quick Start

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # Static export to /out
```

## Stack
- **Framework**: Next.js 15 (App Router, static export)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v3
- **i18n**: Custom React Context — zero external dependencies

## Pages
| Route | Description |
|-------|-------------|
| `/` | Home — Hero, Corporate Highlights, Industry Sectors |
| `/about` | About — Identity, Locations, Leadership, Quality |
| `/products` | Products — 6-product portfolio grid |
| `/contact` | Contact — Validated form + contact details |

## Bilingual Support
Toggle **EN ↔ AR** via the header language button. The UI seamlessly:
- Switches all copy to Arabic / English
- Flips `dir` attribute (`ltr` ↔ `rtl`)
- Applies `Noto Sans Arabic` / `Inter` fonts automatically
